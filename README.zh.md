# Trunook

[Русский](README.md) · [English](README.en.md) · **简体中文**

MacBook 的动态刘海：音乐、会议、剪贴板历史、文件架、笔记，以及向本地模型提问——
都在刘海里完成，而不是散落在各个窗口。

![刘海运行中](docs/demo.gif)

把光标移到刘海上，它会显示正在播放的内容和下一场会议。点按或向下轻扫，
面板完整展开。右键打开全部功能菜单。

![手势](docs/gestures.png)

所有快捷键都使用 ⌃⌥ —— macOS 没有占用这组修饰键。任何一个都可以在设置里
或直接在欢迎窗口中修改。

| 快捷键 | 打开什么 |
|---|---|
| ⌃⌥C | 捕获选中内容并询问模型 |
| ⌃⌥V | 剪贴板历史 |
| ⌃⌥S | 文件暂存架 |
| ⌃⌥T | 计时器与秒表 |
| ⌃⌥M | 系统负载 |
| ⌃⌥P | 提词器 |
| ⌃⌥Z | 新建笔记 |
| ⌃⌥⇧Z | 选中文本直接存为笔记 |
| ⌃⌃ | 开口提问 |
| ⌥⌥ | 按笔记开口提问 |
| ⌃⌥N | 主面板 |
| ⌃⌥1 … ⌃⌥9 | 直接运行命令 |
| ⌃⇧1 … ⌃⇧9 | 按编号粘贴剪贴板记录 |

## 功能

- **音乐。** 曲目、封面、播放控制，以及沿岛屿轮廓的播放进度线。适用于任何
  播放器：数据来自系统。两指轻扫即可切换曲目。
- **日历与提醒。** 在你选定的时间提前提醒，会议链接一键加入，刘海里显示
  倒计时。还能显示 Things 3 里今天的任务。
- **会议控制。** 通话进行时，悬停即可控制麦克风、摄像头、屏幕共享、举手和
  退出。支持浏览器中的 Telemost、Google Meet、Zoom 和 Teams。
- **剪贴板历史。** 保存最近的复制内容，可用键盘按编号粘贴；列表打开时，
  ↑↓ 在各行之间移动，Enter 粘贴选中的一条。
- **文件架。** 把文件拖到刘海上就会落到文件架。再拖到任意窗口即可取出，
  文件会被移走。
- **模型提问。** 按 Enter 发送问题，回答直接写在刘海里，可以复制或粘贴到
  当前窗口。回答的可以是你自己电脑上的 Ollama、其他带 OpenAI 接口的本地服务器
  （LM Studio、llama.cpp、vLLM、Unsloth Studio），也可以是云端服务：OpenAI、
  Anthropic、Gemini、OpenRouter、Groq、DeepSeek。以上地址都会自动填入，
  其余可用自定义提供方接入。可以同时保留多个：各自有独立的地址、密钥和模型，
  命令可以选用其中任意一个的模型。
- **语音助手。** 连按两次 ⌃ 开口提问，连按两次 ⌥ 按笔记提问。面板不会展开：
  刘海会轻轻一震并发光 — 聆听时是蓝色，思考和回答时是模型的颜色 — 旁边还有
  实时音量条，让你看到自己确实被听见。回答很短，模型一边写就一边被读出来；
  刘海里的按钮可以随时打断。点一下刘海就能展开对话用眼睛看。语音在
  **你自己的电脑上**识别，不会外传。
- **笔记。** 同一面板里有模式切换：「AI」是一行提问加回答，「笔记」是带排版的
  多行输入框。笔记名称由模型拟定，模型的回答也能一键存入笔记。打开
  「在笔记中查找」后，模型只根据你的记录回答，而不是凭常识。⌃⌥Z 打开一条
  空笔记；带关键词搜索的列表在同一面板里一键打开，也可以从那里把所有笔记
  导出成 Markdown 文件到文件夹。别人的文字不必重新敲一遍：⌃⌥⇧Z 把任意窗口里
  选中的文本存成笔记，复制过的内容则在剪贴板历史和复制提示条上各有一个按钮。
- **命令。** ⌃⌥C 捕获选中内容并打开与模型的对话：捕获的文本显示在输入框上方，
  命令列表在输入框下方。命令数量不限，可以调整顺序；每条模型提问都有自己的
  模型，显示在该行右侧，按 Tab 或点击即可就地更换。除模型提问外，命令
  还可以是应用、文件夹、链接、AppleScript、macOS「快捷指令」，或把捕获的文本
  存为备忘。
- **计时器与秒表。** 预设时长，二十五分钟的番茄钟并自动准备休息。计时进行时刘海会展开成
  一条并显示计时，点它即可打开面板。时间从启动那一刻算起，即使合上盖子也不会走慢。
- **系统负载。** 处理器、内存和磁盘，带进度条。点击任意指标即可打开「活动监视器」。
- **天气与电源。** 面板角落显示温度图标，天气变化或接上电源时弹出提示。
- **提词器。** 文字就在刘海下方——摄像头所在的位置——支持格式和自动滚动。
  从屏幕中间念稿会让视线偏离镜头。
- **咖啡杯。** 天气旁边的按钮：开启后屏幕不会休眠也不会锁定。
  点击即可在刘海中直接选择时长——半小时、一小时、一个半小时、两小时或不限时；
  倒计时也显示在那里。开启期间刘海会一直向两侧展开：左边是图标，右边是剩余
  时间——点击即可直接回到时长选择。

- **自动更新。**应用每天向 GitHub 查询一次是否有新版本，并在后台下载。
  准备就绪后，刘海处会出现带按钮的提示条：点击即可安装并重启应用。
  下载的内容会用应用自身的签名进行校验，因此已授予的权限在更新后依然有效，
  也无需再次解除隔离。此检查可以关闭。

界面提供俄语、英语和中文，默认跟随系统。

- **外观。**刘海下方的面板由玻璃构成：壁纸透过它可见，而刘海本身保持纯黑——
  岛屿不是浮在屏幕之上，而是从硬件里流出来的。透明度用滑块调节，拖到最右
  即恢复纯黑刘海。玻璃效果需要 macOS 26，更早的系统保持原样。
## 安装

### 从源码构建 —— 更省事的方式

```bash
git clone https://github.com/TruDevLab/Trunook.git
cd Trunook
make cert      # 一次性：生成自签名证书
make install   # 构建、签名并放入「应用程序」
```

需要 Command Line Tools（`xcode-select --install`），不需要 Xcode。

### 使用预编译镜像

从[发布页](../../releases)下载 `.dmg`，把应用拖进「应用程序」，然后清除
隔离标记：

```bash
sudo xattr -r -c /Applications/Trunook.app
```

## 限制

### 没有 Apple 签名

本项目没有付费开发者账号。在别人的 Mac 上门禁不会放行（`spctl -a` 返回
`rejected`），无法公证，也不会上架 App Store。上面的安装顺序正因如此：从源码
构建更省事——你用自己的证书构建的东西，系统不会为难；用镜像则需手动清除隔离
标记。

### 辅助进程使用了 Apple 的命名空间

macOS 通过私有的 `MRMediaRemoteGetNowPlayingInfo` 提供当前曲目信息，而从
macOS 15.4 起普通进程只能拿到空值：只有标识符为 `com.apple.controlcenter.*`
的进程仍可访问。XPC 辅助进程因此得名
`com.apple.controlcenter.TrunookHelper`。

这个做法不会访问他人的数据——它解除的是读取你自己播放器状态的限制。Apple
随时可能在更新中堵上：届时只有曲目名称会消失，绕行本身被隔离在独立服务里。

## 哪些数据会离开你的 Mac

- **更新**——应用每天向 github.com 查询一次是否有新版本，并在后台下载。
  除请求本身外不会有任何数据离开你的 Mac。此检查可以在设置中关闭。
- **天气**——精确到百分之一度（约一公里）的坐标会发送到 open-meteo.com。
  也可以完全不提供定位：在设置或欢迎界面的权限
  步骤中指定城市，应用就不会请求定位权限，只把你输入的名称发送出去。
- **模型提问**发往设置中指定的地址。默认是你自己电脑上的 Ollama；
  若指定了自有服务器，则只发往那里。
- **笔记**保存在应用自己的文件里，不会外传；开启「在笔记中查找」时，
  笔记内容会发给回答问题的同一个模型。
- **剪贴板历史和文件架**都留在本机：历史存在应用自己的文件里，文件架只是
  指向你文件的引用。

## 系统要求

- 带硬件刘海的 MacBook。应用不会显示在外接显示器上。
- macOS 14 或更高版本。刘海玻璃效果需要 macOS 26，更早的系统刘海为纯黑。
- 构建需要 Command Line Tools。
- 模型提问需要单独安装 [Ollama](https://ollama.com) 或任何带 OpenAI 接口的服务器。
